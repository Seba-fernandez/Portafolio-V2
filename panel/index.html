Ingresá con tu token de GitHub. Solo funciona con permiso de escritura sobre el repo del portafolio.

¿Cómo creo el token?
  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: “Only select repositories” → Portafolio-V2.
  3. Permissions → Repository permissions → Contents: “Read and write”. Nada más.
  4. Copiá el token y pegalo acá. Si lo perdés o se filtra, lo borrás en GitHub y creás otro.
